# ShopEasy E-Commerce Website

This project was developed as part of my internship assignment. The objective was to build a responsive e-commerce website using HTML, CSS, and JavaScript while implementing key shopping functionalities such as product listing, product details, cart management, quantity selection, product variations, image zoom, local storage persistence, and responsive design.

The project demonstrates front-end web development skills, JavaScript DOM manipulation, API integration, local storage handling, and user interface design principles.
